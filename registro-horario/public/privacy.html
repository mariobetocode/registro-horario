Política de Privacidad

Última actualización: julio de 2026

Esta aplicación ("Registro de Horarios") es una herramienta interna de uso privado, desarrollada para el control de asistencia (entrada y salida) del personal de un taller. No está dirigida al público general ni recopila datos de usuarios externos.

Qué información se registra

La aplicación almacena únicamente:

  • Nombres de empleados (proporcionados por el administrador del taller)
  • Horarios de entrada y salida registrados diariamente
  • Ajustes de horario y notas administrativas relacionadas con la jornada laboral

No se recopila información sensible, financiera, de ubicación en tiempo real, ni datos biométricos.

Uso de WhatsApp

Esta app puede integrarse con la API de WhatsApp Business (Meta) para permitir el registro de entrada/salida mediante mensajes de texto enviados por el administrador autorizado. Los mensajes procesados se limitan a nombres de empleados y horas, y se usan exclusivamente para actualizar los registros de asistencia. No se comparte esta información con terceros.

Almacenamiento

Los datos se almacenan de forma segura en una base de datos privada (Supabase) asociada exclusivamente a este proyecto. El acceso está restringido al administrador del taller.

No se comparte información con terceros

Los datos registrados en esta aplicación no se venden, comparten ni transfieren a terceros con fines comerciales o publicitarios.

Contacto

Para cualquier duda sobre esta política o sobre el manejo de los datos registrados, contactar al administrador de la aplicación.
